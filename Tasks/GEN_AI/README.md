Generative AI 

## Topics Covered

### 1. What is Generative AI?
Generative AI refers to AI systems that can create new content such as text, images, audio, video, or code based on patterns learned from data.

### 2. Machine Learning
Machine Learning is a branch of AI where systems learn patterns from data and use those patterns to make predictions or decisions without being explicitly programmed for every situation.

### 3. Types of Learning

#### Supervised Learning
The model learns from labelled data, where the correct answer is already provided.

#### Unsupervised Learning
The model works with unlabelled data and identifies patterns or structures on its own.

#### Reinforcement Learning
The model learns by interacting with an environment and receiving rewards or penalties based on its actions.

### 4. Large Language Models (LLMs)
LLMs are AI models trained on large amounts of text data to understand and generate human-like language.

Examples of tasks include:
- Text generation
- Question answering
- Summarization
- Translation
- Code generation

### 5. LLMs vs Other Generative Models
LLMs are mainly designed for language-related tasks, while other generative models can specialize in generating different types of content such as images, audio, or video.

### 6. Tokens
A token is a unit of text processed by an AI model. A token may represent a complete word, part of a word, punctuation, or another piece of text.

### 7. Tokenization
Tokenization is the process of breaking text into tokens before it is processed by an AI model.

Example:

"Hello world!"

can be broken into smaller token units that the model processes.

### Key Takeaways

- Generative AI can create new content.
- Machine Learning allows systems to learn patterns from data.
- Learning can be supervised, unsupervised, or reinforcement-based.
- LLMs specialize in understanding and generating language.
- Tokens are the basic units processed by language models.
- Tokenization converts text into tokens that can be processed by the model.
